## Findings considered and rejected

- Dual-write ClickHouse now: ALGORITHM.md says D1 is the sole primary store; no CH code remains. Spike later if `/data` outgrows D1.
- Self-hosted CRX `update_url` for consumer Chrome: blocked on Windows/macOS without enterprise policy. CWS is the auto-update path.
- Splitting `NewsIngestWorkflow` (~1420 lines): high risk without characterization tests of step order / D1 `batch()`. Defer.
- Replacing `next-themes` / pinning every `^1.0.0` TanStack range: low leverage vs CI and admin auth.
- `chunk()` infinite loop when size is below 1: every production caller passes a positive constant (`SCORE_BATCH_SIZE` 5, `TRANSLATE_BATCH_SIZE` 3, `SOURCE_FETCH_GROUP` 4). Not worth a guard plan.
- MCP `resolveMcpAuth` accepts only `NEWS_ADMIN_TOKEN` (`worker/admin/mcp.ts`): the comment says any other bearer must 401, not fall through. Clerk admin stays on `/api/admin`.
- Public CORS allows `https://*.duyet.net` and `https://*.aidr.today`: public GET, no credentials. Not a finding.
- `llm_calls` insert falls through older column shapes (`worker/llm-call-log.ts`): intentional until every DB has 0035. Not a finding.
- `rowRankSignals` `JSON.parse` of `merged_members`: the SELECT builds that JSON with `json_group_array`. Not a finding.
- Official URL readmission uses the stored row on purpose (`ingest/dedupe.ts` `readmitOfficialRows`: "their stored copy, so the plan matches what D1 holds"). Not a bug that it ignores the just-fetched title.
- `itemVotesTableReady` sticky failure: planned as 006. The later test-only duplicate was not refiled.
- Unused-export sweep (`inferTranslationDirection`, email-intake `normalizeEmail`, and the other names in the debt pass): not one plan. Several sit in files 011 and 025 already touch. Left for a later pass.
- Three `workerd` copies via the direct `miniflare` pin, `cf`, and `wrangler`: real, but the story-OG and Clerk smokes are the deploy gate and this run's children must not run them. Not planned here.
- Feed and vote reads use the global vote and merged-member joins (`ranking.ts` `VOTE_NET_JOIN_*`). Real cost. Not planned here because the narrow join shares `votes.ts` with 006 and the re-rank path must keep the global join.
- One-pass versus three-pass HTML entity decoders (`plain-text.ts` versus `enrich.ts`): real drift. Not planned here. The two test files encode opposite policies, and 008 already owns RSS entity decoding.
