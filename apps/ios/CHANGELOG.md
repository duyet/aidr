# Changelog

## 0.1.0 (build 1)

- First build. The Today tab shows the AI;DR edition: category chips with counts,
  the day block, and the 8 numbered digest rows with thumbnails. Names are blue
  and figures amber, the same as on aidr.today.
- Opens instantly from the last edition saved on the phone, then refreshes.
  Pull down to refresh. With no network it keeps the saved edition and says
  it is offline.
- Vietnamese when the phone is set to Vietnamese, English otherwise.
- Weeks, Calendar and AI;DR tabs are placeholders.
