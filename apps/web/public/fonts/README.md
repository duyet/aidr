# OG card fonts

`be-vietnam-pro-500.ttf` and `be-vietnam-pro-700.ttf` are the only fonts the
story OG card renders with. The card is drawn by satori/resvg, which has no
system font stack: it shapes text exclusively from the `fonts` array the route
passes in, and it does not apply OpenType mark-to-base positioning.

Do not replace these by hand, and do not subset them further without reading
this file.

## Why these outlines, and why the Vietnamese alphabet is mandatory

When satori meets a glyph the loaded fonts do not cover, it does not skip it. It
calls `loadAdditionalAsset`, which fetches a fallback face from Google Fonts over
the network and mixes it into the same run.

Source Sans 3 covers the alphabet, but a stacked Vietnamese tone (`ấ`, `ậ`,
`ế`) is a composite whose vertical offset lives only in the GPOS `mark`
lookup. This renderer ignores that lookup, so the tone mark draws on the
letter. EB Garamond has the same class of failure, and its diacritics collide
even when the lookup is applied. Be Vietnam Pro is a humanist sans in the same
neighbourhood, drawn for Vietnamese, and its stacked letters are simple
outlines with the marks already placed.

The subset spans three separate Unicode blocks, which is the easy thing to get
wrong:

| Characters | Block | Why it is easy to miss |
| --- | --- | --- |
| `Đ` `đ` (U+0110–0111) | Latin Extended-A | Covered by `U+0100-017F` |
| `Ơ` `ơ` (U+01A0–01A1) | Latin **Extended-B** | Falls *outside* `U+0100-017F` |
| `Ư` `ư` (U+01AF–01B0) | Latin **Extended-B** | Falls *outside* `U+0100-017F` |
| U+1EA0–1EF9 (tone block) | Latin Extended Additional | A separate range entirely |

A subset that stops at `U+017F` looks complete while silently dropping every
horned letter. `apps/web/src/lib/og-fonts.ts` exports `VIETNAMESE_ALPHABET`
and a test asserts both weights cover all 130 characters. `gen-og-fonts.py`
also refuses a build whose `ấ` is still a composite or whose mark sits below
the cap height.

## Provenance

Generated by `apps/web/scripts/gen-og-fonts.py` from the static Google Fonts
Be Vietnam Pro files (`ofl/bevietnampro`, Medium and Bold). The script
downloads those files directly.

1. Rewrite the name table so the family is `Be Vietnam Pro` (the upstream
   static files say `Be Vietnam Pro Medium`).
2. `fontTools.subset` keeps latin, latin-ext (through U+024F), combining
   diacriticals, general punctuation, currency, letterlike symbols, arrows,
   math operators, and U+FEFF/U+FFFD.
3. Layout features are limited to positioning ones (`kern`, `mark`, `mkmk`,
   `ccmp`, `calt`, `liga`, `clig`, `locl`, `rlig`).

The upstream URLs track `main`, so a regeneration is not byte-stable. Treat a
hash change as a real change: re-run the OG render tests and look at
`docs/assets/og-story-preview*.png` before committing it.

Regenerate with:

```bash
python3 -m pip install fonttools brotli
python3 apps/web/scripts/gen-og-fonts.py
```

Then refresh the committed previews and review the typographic diff:

```bash
pnpm exec tsx --tsconfig apps/web/tsconfig.json \
  apps/web/scripts/render-og-preview.tsx all docs/assets
```
