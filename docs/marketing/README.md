# Marketing

Copy for talking about AI;DR (https://aidr.today) in public. Every claim here maps to code or to a live page, and `positioning.md` lists the evidence. When the pipeline changes, check the proof points before you reuse a post.

| File | Use it for |
|---|---|
| [positioning.md](positioning.md) | Who it is for, what it does, how it differs, proof points, voice |
| [launch-post.md](launch-post.md) | Launch post in English, plus a short Vietnamese version |
| [social-templates.md](social-templates.md) | X, LinkedIn, Telegram, Facebook, and Hacker News templates, plus daily edition, extension, and MCP posts |

Rules for every post:

- No user counts, testimonials, or benchmarks unless they come from a source you can link.
- Numbers come from code. If `apps/web/ALGORITHM.md` changes a number, change it here too.
- Placeholders use `<angle brackets>`. Fill all of them before you post.
